# Weather Diary - Дневник погоды

## Автор
Татьяна Самокиш

## Описание программы
Weather Diary-это desktop-приложение с графическим интерфейсом для ведения личного дневника наблюдений за погодой. Программа позволяет добавлять записи, фильтровать их по дате и температуре, а также сохранять данные в JSON-файл для дальнейшего использования.

## Как запустить
```bash
python weather_diary.py
